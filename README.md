# Block Shooter - A Web-Based Arcade Game

# Description

This is a web-based arcade game built using HTML, CSS, and JavaScript. In this game, the player controls a spaceship, shooting at multiple blocks that move back and forth. The goal is to avoid getting hit by the block bullets while trying to destroy the blocks by shooting them down.

# Features:
- Multiple Blocks: The game has 3 blocks that move left and right across the screen, shooting bullets at the player.
- Player Controls: Move the spaceship left and right with the arrow keys and shoot with the spacebar.
- Collision Detection: Detects when a player's bullet hits a block or when a block's bullet hits the player.
- Score Tracking: The player's score increases every time a block is hit.
- Game Over: The game ends when a block bullet hits the player, displaying a "Game Over" message.

# How to Play:
1. Use the Left/Right Arrow keys to move your spaceship horizontally across the bottom of the screen.
2. Press the Spacebar to shoot bullets at the blocks.
3. Try to destroy as many blocks as possible while avoiding their bullets.
4. The game ends when a block's bullet hits the player. The final score will be displayed.

# Technologies Used:
- HTML: For structuring the game interface.
- CSS: For styling the player, blocks, and bullets.
- JavaScript: For handling the game logic, including player movement, shooting, bullet collision detection, and score updating.
